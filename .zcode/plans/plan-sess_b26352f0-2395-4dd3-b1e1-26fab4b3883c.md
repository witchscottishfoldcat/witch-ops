## Agent 对话记忆模块

### 目标
在导航栏新增独立的"对话记忆"页面,作为 Agent 历史会话的档案馆(浏览/搜索/预览/删除/继续对话),与 AgentCopilot(实时对话)职责分离。

### 改动文件(4 个)

**1. `src/components/Sidebar.tsx`** — 新增导航项
- 在"AI 智能与 SOP"组里,Agent Copilot 和 SOP 技能库之间,新增:
  `{ id: 'agent_memory', label: '对话记忆', icon: History, badge: 会话总数 }`
- badge 从 AppContext 获取会话列表数量

**2. `src/components/AgentMemory.tsx`** — 新建,核心页面
双栏布局(类似 DocsHub):
- **左侧(280px)**:搜索框(按标题模糊匹配) + 会话列表
  - 每条卡片:标题、更新时间、关联服务器名、消息数
  - 删除按钮(两步确认)
  - 点击选中 → 右侧显示完整对话
- **右侧**:选中会话的只读消息预览
  - 消息气泡(user 蓝/agent 紫,复用 AgentChatPanel 的视觉风格)
  - proposal 卡片只读展示(命令 + 执行结果)
  - 顶部操作栏:"继续对话"按钮 → `setActiveView('agent')` + 选中该会话

**3. `src/App.tsx`** — 注册新视图
- `{activeView === 'agent_memory' && <AgentMemory />}`

**4. `src/context/AppContext.tsx`** — 暴露会话列表状态
- 加 `agentSessions: AgentSessionInfo[]` 和 `refreshAgentSessions()` 到 context
- AgentMemory 和 Sidebar 的 badge 共用,避免各自重复请求

### 数据来源(全部复用已有后端 API,无后端改动)
- `ipc.listAgentSessions()` → 会话列表
- `ipc.loadAgentMessages(id)` → 会话消息内容
- `ipc.deleteAgentSession(id)` → 删除
- 关联服务器名:从 `servers` 列表按 `server_id` 查找

### 搜索策略
前端按标题模糊匹配(简单高效)。选中会话后加载完整消息内容。

### 与 AgentCopilot 的关系
- AgentCopilot 保留自己的会话切换栏(快速切换,适合对话中切换上下文)
- 对话记忆模块是"档案馆"(浏览全部历史、搜索、预览、删除管理)
- 两者共享 `activeSessionId`(localStorage 持久化),记忆页点"继续对话"后跳到 Agent 页,自动选中该会话
